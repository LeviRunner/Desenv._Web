5. Listas HTML 📑

Listas são estruturas fundamentais em HTML para organizar e apresentar informações de forma clara e hierárquica. Existem três tipos principais de listas em HTML.

Tipos de Listas HTML

1. Listas Não Ordenadas (<ul>)

Usadas quando a ordem dos itens não importa. Cada item é precedido por um marcador (bullet).

Resultado Visual
  • Maçã
  • Banana
  • Laranja
  • Morango
Código HTML
<ul>
  <li>Maçã</li>
  <li>Banana</li>
  <li>Laranja</li>
  <li>Morango</li>
</ul>

2. Listas Ordenadas (<ol>)

Usadas quando a ordem dos itens é importante. Cada item é numerado sequencialmente.

Resultado Visual
  1. Prepar os ingredientes
  2. Misturar farinha e açúcar
  3. Adicionar ovos
  4. Assar por 30 minutos
Código HTML
<ol>
  <li>Preparar</li>
  <li>Misturar</li>
  <li>Adicionar</li>
  <li>Assar</li>
</ol>

3. Listas de Descrição (<dl>)

Usadas para pares de termo e descrição. Útil para glossários, definições e especificações.

Exemplo: Glossário Técnico
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language - linguagem de marcação para web</dd>
  
  <dt>CSS</dt>
  <dd>Cascading Style Sheets - linguagem de estilos</dd>
  
  <dt>JavaScript</dt>
  <dd>Linguagem de programação para interatividade web</dd>
</dl>
Resultado
HTML
HyperText Markup Language - linguagem de marcação para web
CSS
Cascading Style Sheets - linguagem de estilos
JavaScript
Linguagem de programação para interatividade web

Atributos Comuns em Listas

<ol> - Atributos Especiais

Atributo Descrição Exemplo
start Número inicial da lista <ol start="5">
reversed Inverte a ordem dos números <ol reversed>
type Tipo de numeração <ol type="a">
Exemplos de Numeração com type:

type="1" (padrão):

  1. Primeiro
  2. Segundo
  3. Terceiro

type="A" (letras maiúsculas):

  1. Primeiro
  2. Segundo
  3. Terceiro

type="a" (letras minúsculas):

  1. Primeiro
  2. Segundo
  3. Terceiro

type="I" (romanos maiúsculos):

  1. Primeiro
  2. Segundo
  3. Terceiro

Boas Práticas para Listas

  • ✅ Use <ul> para itens sem ordem específica
  • ✅ Use <ol> para sequências ou processos
  • ✅ Use <dl> para pares termo-definição
  • ✅ Aninha listas apenas quando necessário para hierarquia
  • ✅ Sempre coloque <li> dentro de <ul>, <ol> ou <dl>
  • ✅ Adicione títulos ou contexto descritivo para listas complexas
  • ✅ Use aria-label ou aria-describedby para acessibilidade
  • ✅ Mantenha listas simples e legíveis
  • ✅ Evite ninhagens muito profundas (máximo 3 níveis)

Exemplo Prático Completo

Estrutura de um Menu com Submenu

<nav>
    <ul>
        <li><a href="/">Início</a></li>
        <li>
            <a href="/servicos">Serviços</a>
            <ul>
                <li><a href="/servicos/design">Design</a></li>
                <li><a href="/servicos/dev">Desenvolvimento</a></li>
                <li><a href="/servicos/seo">SEO</a></li>
            </ul>
        </li>
        <li><a href="/contato">Contato</a></li>
    </ul>
</nav>
💡 Dica: Listas são muito importantes para SEO e acessibilidade. Um bom uso de listas melhora a legibilidade para humanos e máquinas!
