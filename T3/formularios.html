3. Formulários HTML 📋

Formulários são elementos essenciais para coletar dados dos usuários. Eles permitem interatividade e comunicação entre o usuário e a aplicação web.

Elementos Básicos de um Formulário

Estrutura de um Formulário

Um formulário é delimitado pela tag <form> e contém diversos campos de entrada. 

<form action="/processar" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">
    <button type="submit">Enviar</button>
</form>

Atributos Importantes da Tag Form

Atributo Descrição Exemplo
action URL para processar o formulário action="/formulario"
method Método HTTP: GET ou POST method="POST"
name Nome único do formulário name="meuFormulario"
enctype Tipo de codificação dos dados enctype="multipart/form-data"

Tipos de Input Disponíveis

Tabela de Tipos de Input

Tipo Descrição Exemplo
text Campo de texto simples <input type="text">
email Campo de email com validação <input type="email">
password Campo de senha (mascarado) <input type="password">
number Campo para números <input type="number">
date Seletor de data <input type="date">
radio Seleção única em grupo <input type="radio">
checkbox Múltiplas seleções <input type="checkbox">
submit Botão para enviar <input type="submit">
reset Botão para limpar <input type="reset">
file Upload de arquivo <input type="file">

Dicas para Criar Formulários Acessíveis

  • ✅ Sempre use <label> associada com for e id
  • ✅ Use fieldset e legend para agrupar campos
  • ✅ Adicione atributo required em campos obrigatórios
  • ✅ Use tipos de input específicos (email, tel, date, etc)
  • ✅ Adicione placeholders descritivos
  • ✅ Indique campos obrigatórios visualmente com asterisco (*)
  • ✅ Use mensagens de erro claras e construtivas
  • ✅ Teste com leitores de tela
💡 Dica: Sempre valide os dados no servidor, mesmo que faça validação no cliente. Nunca confie apenas em validações do lado do cliente!
