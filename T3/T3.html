1. Elementos em Linha vs Elementos em Bloco

Span (elemento em linha): É um elemento em linha que não quebra o conteúdo, apenas agrupa o texto de forma semântica sem ocupar toda a largura da página.

Div (elemento em bloco): Diferentemente do span, a div quebra o conteúdo e ocupa toda a largura disponível. É muito utilizada para agrupar elementos e criar layouts.

3. Tags HTML Obsoletas (Substituídas por CSS)

As seguintes tags foram descontinuadas nas versões mais recentes do HTML5 porque seus efeitos são melhor alcançados através de CSS:

  • <image> → Use <img> em seu lugar
  • <font> → Use CSS (font-family, font-size)
  • <dir> → Use <ul> para listas não ordenadas
  • <center> → Use CSS (text-align: center)
  • <applet> → Use <object> ou <embed>

4. Tipos de Listas em HTML

4.1 Lista Ordenada (OL - Ordered List)

Usada quando a sequência importa. Exemplo - Passos para criar um projeto web:

  1. Definir os requisitos do projeto
  2. Criar o protótipo em papel ou Figma
  3. Estruturar o HTML semântico
  4. Estilizar com CSS
  5. Adicionar interatividade com JavaScript
  6. Testar em diferentes navegadores

4.2 Lista Não Ordenada (UL - Unordered List)

Usada quando não há ordem específica. Exemplo - Tecnologias necessárias:

  • HTML5
  • CSS3
  • JavaScript ES6+
  • Git/GitHub
  • Responsive Design
  • AJAX/Fetch API

4.3 Lista de Definições (DL - Definition List)

Usada para termos e suas definições. Exemplo - Glossário Front-end:

HTML
HyperText Markup Language - Linguagem de marcação usada para criar páginas web
CSS
Cascading Style Sheets - Linguagem usada para estilizar e fazer layout de documentos HTML
JavaScript
Linguagem de programação que adiciona interatividade às páginas web do lado do cliente
Responsive Design
Abordagem de design que torna as páginas web adaptáveis a diferentes tamanhos de tela

5. Formulários HTML

Os formulários são elementos fundamentais para coletar dados do usuário. Veja as tags principais:

5.1 Tags de Formulário

Tag Descrição Uso
<form> Container principal do formulário. Envolve todos os campos do formulário
<input> Campo do formulário. Usa o atributo "type" para informar o tipo a ser utilizado. text, email, password, number, date, etc.
<textarea> Campo de texto de múltiplas linhas. Comentários, mensagens longas
<select> e <option> Campos de seleção. <select> é o container e <option> são os itens. Listas suspensas
<button> Campo de botão que permite executar ações – enviar, limpar, etc. submit, reset, button
<label> Define um título ou legenda que descreve para que serve cada campo. Associar texto aos campos
