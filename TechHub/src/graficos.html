Esta página demonstra como podemos utilizar o Chart.js para transformar dados de tabelas HTML em gráficos interativos. Os dados abaixo são extraídos dinamicamente da tabela por meio de JavaScript.

💡 Conceito Importante:

O JavaScript lê os dados da tabela HTML e os transforma em um gráfico visual. Isso demonstra como o DOM (Document Object Model) pode ser manipulado para criar experiências interativas.

🔧 Como Funciona?

Processo de Funcionamento:

  1. Leitura do DOM: O JavaScript localiza a tabela HTML usando document.getElementById()
  2. Extração de Dados: Utiliza querySelectorAll() para obter todas as linhas
  3. Processamento: Itera sobre as células e extrai os valores usando innerText
  4. Renderização: O Chart.js cria o gráfico com os dados extraídos

📚 Vantagens dessa Abordagem:

  • Manutenibilidade: Altere os dados na tabela e o gráfico se atualiza automaticamente
  • Reutilização: O mesmo código pode ser aplicado a diferentes tabelas
  • Responsividade: O Chart.js se adapta a diferentes tamanhos de tela
  • Interatividade: Os gráficos do Chart.js possuem tooltips e animações
  • Performance: Leve e rápido, sem dependências pesadas

💻 Exemplos de Código:

Extração de dados da tabela em JavaScript:

const tabela = document.getElementById('dados-vendas');
const linhas = tabela.querySelectorAll('tbody tr');

const labels = [];
const valores = [];

linhas.forEach(linha => {
    labels.push(linha.cells[0].innerText);
    valores.push(parseFloat(linha.cells[1].innerText));
});

Criação do gráfico com Chart.js:

const ctx = document.getElementById('meuGrafico').getContext('2d');
new Chart(ctx, {
    type: 'bar', // 'line', 'pie', 'doughnut', etc.
    data: {
        labels: labels,
        datasets: [{
            label: 'Vendas Mensais',
            data: valores,
            backgroundColor: 'rgba(54, 162, 235, 0.5)',
            borderColor: 'rgba(54, 162, 235, 1)',
            borderWidth: 1
        }]
    }
});
