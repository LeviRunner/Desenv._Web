3. Formulários HTML 📋

Formulários são elementos essenciais para coletar dados dos usuários. Eles permitem interatividade e comunicação entre o usuário e a aplicação web.

Elementos Básicos de um Formulário

Estrutura de um Formulário

Um formulário é delimitado pela tag <form> e contém diversos campos de entrada. 

<form action="/processar" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">
    <button type="submit">Enviar</button>
</form>

Atributos Importantes da Tag Form

Atributo Descrição Exemplo
action URL para processar o formulário action="/formulario"
method Método HTTP: GET ou POST method="POST"
name Nome único do formulário name="meuFormulario"
enctype Tipo de codificação dos dados enctype="multipart/form-data"

Agrupamento com Fieldset e Legend

Estruturando Formulários com Fieldset e Legend

A tag <fieldset> é utilizada para agrupar campos relacionados em um formulário, melhorando a organização visual e semântica. Isso fica ainda mais claro quando vinculamos ao <fieldset> a tag <legend>, que fornece um título descritivo para o grupo de campos. 

<fieldset>
    <legend>Informações Pessoais</legend>
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">
</fieldset>

Benefícios:

  • Melhor organização visual do formulário
  • Semântica mais clara para leitores de tela
  • Facilita a compreensão da estrutura do formulário para usuários
  • Agrupa logicamente campos relacionados

Atributos de Formulários HTML

Atributos e suas Funções

Como vimos, é necessária uma atenção especial aos atributos quando tratamos de formulários. Para melhor visualização e entendimento, todos os atributos contidos no código mencionado são descritos a seguir:

Tag Atributo Função
<form> action Define a URL (endereço) para a qual os dados do formulário serão enviados.
<form> method Define o método HTTP (POST ou GET) para envio dos dados.
<label> for Vincula a tag <label> ao campo ao qual ela se refere. Esse vínculo faz com que seja possível clicar na label para ativar o campo relacionado.
<input> minlength, maxlength Define a quantidade de caracteres mínima e máxima, respectivamente, permitida em um campo.
<input> e <button> type Define o tipo do campo e, sobretudo, como ele se comporta.
<option> value Define o valor do campo, e também pode ser utilizado na tag <input>. No caso da <option>, os seus valores possíveis são previamente definidos quando a página é codificada. Já na <input>, embora também possa ser previamente definido, normalmente é o usuário quem define o seu valor.

Novos Atributos e Tipos HTML5

Atributos HTML5 para Formulários

Pensando nas deficiências citadas, a HTML5 definiu novos tipos de entrada e também novos atributos relacionados a formulários. Destacamos alguns desses novos atributos e tipos:

Atributo Função Comentário
placeholder Exibir um texto no campo de input. Utilizado para dar uma dica ao usuário sobre o dado a ser inserido.
required Determinar se um campo é obrigatório. Utilizado na validação dos dados de um formulário.
autofocus Fixar o foco no campo. Utilizado quando desejamos que, ao carregar o formulário, um determinado campo seja focado.
pattern Validar o valor de um campo com base em uma expressão regular (RegEX). O campo de tel. é um bom exemplo de utilização desse atributo. Com ele podemos, por exemplo, determinar a quantidade de caracteres e o formato esperado para um campo.

Novos Tipos de Input HTML5

Tipo Função Comentário
tel Inserir números de telefone. Para uma melhor usabilidade, deve ser usado em conjunto com o atributo "pattern".
datetime Inserir datas com o fuso horário em UTC a partir de um calendário. Fornece interface intuitiva para seleção de data e hora.
date Inserir datas sem fuso horário a partir de um calendário. Seletor de data nativo en navegadores modernos.
number Inserir números. Cria um componente diferente do input normal, em que, por meio de setas, os números podem ser incrementados ou decrementados.

Validação de Formulários

Importância da Validação de Dados

Para explicarmos a criação de um formulário HTML, apresentamos tags e atributos que nos permitem montar um formulário já funcional, pronto para ser preenchido e submetido. Entretanto, há outro aspecto relacionado a esses elementos que precisa ser discutido: a validação de dados.

A validade dos dados concorre com a utilização das tags corretas que permitam a melhor experiência possível aos usuários. Podemos dizer que, ao pensarmos na estrutura do formulário, nas tags e nos atributos, estamos pensando em quem vai preencher o formulário.

Exemplo Prático de Validação

Imagine que podemos permitir a inserção de uma data de nascimento com a digitação de valores ou a partir da seleção em um elemento do tipo calendário. Agora pense em quem vai receber as informações provenientes do formulário. Em um campo de texto simples, sem nenhum tipo de padrão, serão recebidas as mais variadas combinações de dados. Por exemplo:

  • 01 de janeiro de 1980
  • 01/01/1980
  • 01011980

Imaginando esse cenário, é possível entender a importância da validação das informações. Ao usar a entrada de tipo date, o navegador garante um formato padrão consistente.

Como Funciona a Validação?

A validação é um processo que pode e deve ocorrer tanto no lado cliente – no navegador – quanto no lado servidor. Pensando no lado cliente, essa ação ocorre assim que o formulário é submetido, antes que os dados sejam recebidos pelo servidor de destino.

Há pouco tempo, para validar um formulário, era necessário usar o JavaScript. Entretanto, na HTML5 é possível fazê-lo de forma nativa, sem o uso de linguagens de programação.

Tipos de Validação HTML5

Na HTML5, há dois tipos possíveis de validação:

1. Tipagem

Um tipo verifica se o dado inserido em um campo é consistente com o seu tipo e/ou padrão (pattern).

Quanto à primeira validação, podemos citar novamente o elemento <input> do tipo "email". Um endereço de e-mail é um dado que possui uma formatação predefinida: precisa ter o "@"; precisa ter a extensão de domínio ".com / .com.br" etc. 

<input type="email" id="email" name="email" required>

Logo, declarar uma tag <input> com o type="email" faz com que, naturalmente, seja validado o seu conteúdo.

2. Validação com Pattern

Algo semelhante acontece com a utilização do atributo pattern, sendo que, nesse caso, é você quem define o que um campo precisa conter para ser considerado válido. Por exemplo: determinar o formato desejado para um campo que receba um número de telefone.

Você pode definir que ele contenha o DDD, com dois caracteres numéricos, seguido por dois conjuntos de números – um contendo 5 e outro contendo 3 ou 4 caracteres: 

<input type="tel" id="telefone" name="telefone" 
        pattern="[0-9]{2}-[0-9]{5}-[0-9]{3,4}$" 
        placeholder="(XX) XXXXX-XXXX" required>
3. Campos Obrigatórios

Além da validação pelo tipo de dado, há também a validação de campos obrigatórios. Logo, quando precisamos que determinado campo não fique em branco, usamos o atributo required. 

<input type="text" id="nome" name="nome" required>

Desabilitando Validação Nativa

O comportamento padrão da HTML5 é validar os dados quando ocorre o envio do formulário. Entretanto, é possível desativar essa funcionalidade. Para isso, deve ser atribuído o atributo novalidate à tag <form>. 

<form action="/processar" method="POST" novalidate>
    <!-- Campos do formulário -->
</form>

⚠️ Atenção: Ao desabilitar validação nativa, você é responsável por implementar validação via JavaScript ou no servidor.

Resumo dos Atributos de Validação

Atributo Função Exemplo
required Torna o campo obrigatório <input type="text" required>
minlength Define número mínimo de caracteres <input type="text" minlength="8">
maxlength Define número máximo de caracteres <input type="text" maxlength="50">
pattern Valida com expressão regular <input type="tel" pattern="[0-9]{2}-[0-9]{5}-[0-9]{3,4}">
type Valida pelo tipo (email, number, date, etc) <input type="email">
novalidate Desabilita validação nativa (na form) <form novalidate>

Dicas para Criar Formulários Acessíveis

  • ✅ Sempre use <label> associada com for e id
  • ✅ Use fieldset e legend para agrupar campos
  • ✅ Adicione atributo required em campos obrigatórios
  • ✅ Use tipos de input específicos (email, tel, date, etc)
  • ✅ Adicione placeholders descritivos
  • ✅ Indique campos obrigatórios visualmente com asterisco (*)
  • ✅ Use mensagens de erro claras e construtivas
  • ✅ Teste com leitores de tela
💡 Dica: Sempre valide os dados no servidor, mesmo que faça validação no cliente. Nunca confie apenas em validações do lado do cliente!
