2. Tags Semânticas e suas Funções 📝

As tags HTML semânticas fornecem significado ao conteúdo além de apenas apresentação visual.

Elementos em Linha vs Elementos em Bloco

<span> (elemento em linha): É um elemento em linha que não quebra o conteúdo, apenas agrupa o texto de forma semântica sem ocupar toda a largura da página.

Exemplo: Elemento DIV (Bloco)

<div> (elemento em bloco):

Diferentemente do span, a div quebra o conteúdo e ocupa toda a largura disponível. É muito utilizada para agrupar elementos e criar layouts. 

<div style="background-color: #e3f2fd; padding: 15px; border-radius: 5px;">
    Conteúdo da div aqui
</div>

Tags de Estrutura Semântica

Tag <header>

Representa o cabeçalho de um documento ou seção. Geralmente contém títulos, subtítulos, logotipos e informações de navegação. 

<header>
    <h1>Título Principal</h1>
    <nav>Menu de navegação</nav>
</header>

Uso: Uma vez por página, no início do documento.

Tag <nav>

Define uma seção com links de navegação. Deve ser usada para agrupar links de navegação principais. 

<nav>
    <a href="/inicio">Início</a>
    <a href="/sobre">Sobre</a>
    <a href="/contato">Contato</a>
</nav>

Tag <main>

Especifica o conteúdo principal do documento. Deve haver apenas uma tag main por página. 

<main>
    <section>Conteúdo principal aqui</section>
</main>

Tag <section>

Define uma seção temática do documento. Agrupa conteúdo relacionado. 

<section id="sobre">
    <h2>Sobre Nós</h2>
    <p>Informações sobre a empresa...</p>
</section>

Tag <article>

Representa conteúdo independente, como um artigo de blog, notícia ou post. 

<article>
    <h3>Título do Artigo</h3>
    <p>Conteúdo do artigo...</p>
</article>

Tag <aside>

Define conteúdo relacionado indiretamente ao conteúdo principal, como uma barra lateral. 

<aside>
    <h3>Tópicos Relacionados</h3>
    <ul>
        <li>Link 1</li>
        <li>Link 2</li>
    </ul>
</aside>

Tag <footer>

Representa o rodapé de um documento ou seção. Geralmente contém informações de copyright, links e contatos. 

<footer>
    <p>© 2026 Minha Empresa</p>
    <nav>
        <a href="#">Privacidade</a>
        <a href="#">Termos</a>
    </nav>
</footer>

Outros Elementos Semânticos Importantes

Tag <strong>

Indica uma importância forte. Navegadores renderizam como texto em negrito.

Diferença: <strong> é semântico, <b> é apenas visual.

Tag <em>

Enfatiza texto. Navegadores renderizam como texto em itálico.

Diferença: <em> é semântico, <i> é apenas visual.

Exemplo Completo de Estrutura Semântica

<!DOCTYPE html>
<html>
<head>
    <title>Meu Site</title>
</head>
<body>
    <header>
        <h1>Título do Site</h1>
        <nav><a href="#">Menu</a></nav>
    </header>
    
    <main>
        <section>
            <article>
                <h2>Artigo 1</h2>
                <p>Conteúdo...</p>
            </article>
        </section>
        
        <aside>
            <h3>Sidebar</h3>
            <!-- Conteúdo relacionado -->
        </aside>
    </main>
    
    <footer>
        <p>© 2026</p>
    </footer>
</body>
</html>

Benefícios das Tags Semânticas

  • ✅ SEO: Mecanismos de busca entendem melhor o conteúdo
  • ✅ Acessibilidade: Leitores de tela interpretam corretamente
  • ✅ Manutenção: Código mais legível e fácil de manter
  • ✅ Compatibilidade: Funciona em todos os navegadores modernos
  • ✅ Responsividade: Facilita a criação de sites adaptativos
💡 Dica: Use sempre as tags semânticas apropriadas. Evite usar apenas <div> para tudo! Isso melhora a qualidade do seu código e a experiência do usuário.
