4. Tabelas HTML 📊

Tabelas são usadas para apresentar dados estruturados de forma clara e organizada. HTML oferece tags específicas para criar tabelas acessíveis e semânticas.

Estrutura Básica de uma Tabela

Componentes de uma Tabela

<table>
    <thead>
        <tr>
            <th>Cabeçalho 1</th>
            <th>Cabeçalho 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Dados 1</td>
            <td>Dados 2</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>Rodapé 1</td>
            <td>Rodapé 2</td>
        </tr>
    </tfoot>
</table>

Atributos Importantes de Tabelas

Colspan e Rowspan

colspan: Faz uma célula ocupar múltiplas colunas
rowspan: Faz uma célula ocupar múltiplas linhas 

<thead>
    <tr>
        <th rowspan="2">Categoria</th>
        <th colspan="3">Dados Trimestrais</th>
    </tr>
    <tr>
        <th>Q1</th>
        <th>Q2</th>
        <th>Q3</th>
    </tr>
</thead>

Tags Semânticas para Tabelas

Funcionalidades Importantes

  • <table>: Container principal da tabela
  • <thead>: Cabeçalho da tabela (linhas títulos)
  • <tbody>: Corpo principal com dados
  • <tfoot>: Rodapé da tabela (totais, resumos)
  • <tr>: Linha da tabela
  • <th>: Célula de cabeçalho
  • <td>: Célula de dados
  • <caption>: Título/legenda da tabela

Boas Práticas para Tabelas

  • ✅ Sempre use <thead>, <tbody> e <tfoot>
  • ✅ Use <th> para cabeçalhos, não <td>
  • ✅ Adicione <caption> para descrever a tabela
  • ✅ Use atributos de escopo em cabeçalhos (scope="col", scope="row")
  • ✅ Adicione aria-label ou aria-describedby para acessibilidade
  • ✅ Evite tabelas muito largas - considere responsividade
  • ✅ Não use tabelas para layout de página!
  • ✅ Destaque visualmente cabeçalhos e rodapés
