Pseudo-classes (:hover, :active, :focus, :disabled)

Interatividade com mudanças de estilo baseadas em estados.

.btn:hover { transform: translateY(-2px); }
.btn:active { transform: translateY(0); }
.btn:focus { outline: 3px solid #f39c12; }
.btn:disabled { opacity: 0.6; }

Crie animações suaves e contínuas sem usar JavaScript.

Pulse
↻

Design Responsivo (@media queries)

Adapte o layout para diferentes tamanhos de tela (redimensione a janela).

Desktop

Em telas grandes, mostramos todos os elementos lado a lado.

Tablet

Em telas médias, ajustamos o layout para melhor visualização.

Mobile

Em telas pequenas, o layout se adapta verticalmente.

@media (max-width: 768px) {
  .elemento { /* estilos para telas pequenas */ }
}

Resumo das Principais Utilizações de CSS

Seletores: Selecione elementos por tipo, classe, ID, atributo
Cores: Sólidas, gradientes, RGBA para transparência
Tipografia: Tamanho, peso, espaçamento, transformação de texto
Box Model: Margin, padding, border, box-shadow
Posicionamento: Static, relative, absolute, fixed, sticky
Flexbox: Layout flexível e responsivo 1D
Grid: Layout em grade 2D poderoso
Pseudo-classes: Estados de elementos (:hover, :focus, etc)
Pseudo-elementos: ::before, ::after, ::first-line, ::first-letter
Animações: @keyframes para movimentos suaves
Transformações: Scale, rotate, skew, translate
Responsividade: @media queries para diferentes telas
