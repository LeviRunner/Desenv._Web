## 🛠️ Para Desenvolvedores

### Habilitar/Desabilitar Auto-Login

O auto-login está definido em cada arquivo HTML. Se quiser desativar:

**Arquivo:** `src/T3/<pagina>.html`

```javascript
// Comente ou remova este bloco se quiser desativar
if (urlParams.get('teste') === 'ativo') {
    // Auto-login logic...
}
```

### Personalizar Dados de Teste

Edite o arquivo de página (ex: `index.html`):

```javascript
if (urlParams.get('teste') === 'ativo') {
    localStorage.setItem('usuarioTechHub', JSON.stringify({
        nome: 'Seu Nome Aqui',  // ← Mude aqui
        email: 'seu@email.com', // ← Mude aqui
        nick: 'seu_nick',       // ← Mude aqui
        dataRegistro: new Date().toLocaleDateString('pt-BR')
    }));
}
```
